MettleMiles Website & Mobile Application

Product Requirement Document (PRD)

Project Name

MettleMiles

Tagline

Run Through History

Objective

Develop a world-class marathon website and mobile application that delivers an end-to-end digital experience for runners, sponsors, volunteers, organizers, tourism partners, and media. The platform should be scalable to support future marathon events while positioning Rajgir Marathon as India’s leading heritage marathon.

⸻

Project Goals

The platform should enable users to:

Discover Rajgir Marathon

Register for events

Complete online payments

Manage race participation

Join running communities

Invite friends and co-runners

Form corporate or social teams

Track training progress

Access race-day information

View live results

Download certificates

Access race photos and memories

Explore Rajgir tourism

Engage with sponsors

Participate in future events


The system should also provide comprehensive dashboards for organizers, sponsors, volunteers, vendors, and administrators.
